# 🌱 Agro Forte e Sustentável

## 📖 Sobre o Projeto

O **Agro Forte e Sustentável** é um site desenvolvido para conscientizar sobre a importância do equilíbrio entre a produção agrícola e a preservação do meio ambiente. O projeto apresenta informações sobre práticas sustentáveis no agronegócio, destacando como a tecnologia e a responsabilidade ambiental podem caminhar juntas para garantir produtividade e conservação dos recursos naturais.

---

## 🎯 Objetivo

Promover a conscientização sobre:

- Produção agrícola sustentável;
- Uso responsável dos recursos naturais;
- Redução dos impactos ambientais;
- Conservação da água e do solo;
- Uso de energias renováveis no campo;
- Equilíbrio entre crescimento econômico e preservação ambiental.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5** → Estrutura do site;
- **CSS3** → Estilização e responsividade;
- **JavaScript** → Interatividade e funcionalidades.
